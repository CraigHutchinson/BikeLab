# Canonical guided launch contract

The short trail preset opts into `scenario.numerics: "canonical-guided-0.1"`, recorded as `bikelab-trail-bike-0.5`. Fixed and guided riders are supported. Articulated initialization remains a separate contract. Old records without this selector retain their original XML, launch and force calculation path; replay never upgrades them implicitly.

The original `.4` full-suspension trail fails its established 1e-7 normalized comparison budget in both [Edge](evidence/iteration-20-guided-edge-portability.json) and [pinned Chromium](evidence/iteration-20-guided-pinned-portability.json). Pinned CI first reports a smaller exact residual mismatch; complete diagnostic comparison finds a maximum normalized difference of 4.1880191425924806e-7. Initial recorded body positions, energy and momentum match. A particular operation has not been isolated as the sole cause. These failed records remain historical evidence.

The new policy defines numeric native XML attributes at 12 significant decimal digits before compilation, including the existing near-zero spring-reference rule. Derived named scalar launch coordinates and rates are rounded once to 12 significant digits before initial observation, with fresh time zero and zero warm seed. This explicitly defines a new launch; evolving state, supplied articulated states and exported results are never rounded to disguise divergence. The receipt owns ordinary JavaScript numbers before awaiting its XML SHA-256, so native memory growth cannot detach its coordinate data.

For full suspension, native rest tendon length, current tendon length and velocity, and the always-sparse native tendon Jacobian drive the shock buffer. With shock compression q = L0 - L, compression rate is -dL/dt and generalized buffer force is -B J, where J = dL/dq_native. Eye-force normalization uses the same native tendon length. This is the already reviewed canonical articulated force mapping, selected for this new model as well. Hardtail has no shock tendon. Ultimate travel, tyre/rim, penetration, pitch and temporal-motion guards are unchanged. These limits stop unsupported motion; they do not simulate fracture or pressure loss.

Primary references read before implementation:

- Pinned MuJoCo [`mj_fwdVelocity`](https://github.com/google-deepmind/mujoco/blob/a892750516336d8358949f4518fcc4fbbd85beae/src/engine/engine_forward.c): tendon velocity is the sparse tendon Jacobian multiplied by generalized velocity.
- Pinned MuJoCo [`mj_springdamper`](https://github.com/google-deepmind/mujoco/blob/a892750516336d8358949f4518fcc4fbbd85beae/src/engine/engine_passive.c): tendon scalar forces project through that Jacobian into generalized forces.
- [ECMAScript Math](https://tc39.es/ecma262/multipage/numbers-and-dates.html#sec-math-object): transcendental results are implementation approximations. Host diagnostic atan2/hypot leaves are not promised universally bit-identical.

`numericalPolicy` records precision, native build, XML hash, named applied q/v, fresh-run semantics and force-mapping version. It is a recomputed launch receipt, not an imported checkpoint or a complete physical identity. Replay validates the complete scenario and recomputes it. The new browser check requires this receipt exactly, all record structure and nonnumeric values exactly, and every numeric record leaf within 1e-9 * max(1, abs(Node value)). It reports maximum absolute/normalized difference and whether all values were exact. This is the established articulated budget, 100 times stricter than the failed historical guided budget; no legacy tolerance is widened. Physical calibration, convergence and browser agreement are separate qualifications.

Focused tests cover both bikes and fixed/guided modes, native coordinate application, XML receipt, exact same-runtime JSON replay, observation-cadence independence, invalid selectors and version mixing. Hosted checks cover the actual short-trail preset, mode conversion, complete Node replay and desktop/mobile captures. Final PR-head hosted tests and complete pinned-browser comparisons pass; both canonical trail records agree exactly in the observed run. See the [receiving receipt](evidence/iteration-20-canonical-browser.json). Final trail capture inspection is still pending while the combined artifact is split into captures/records. No general newer-browser qualification is claimed.
